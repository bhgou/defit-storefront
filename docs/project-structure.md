# Структура проекта

```text
WebApplication1/
├── Common/                    # Общий код без бизнес-логики
│   ├── Api/                   # Ошибки, фильтры, middleware
│   ├── Application/           # Общие интерфейсы и сценарии
│   ├── Domain/                # Базовые типы сущностей
│   └── Infrastructure/        # База, файлы, внешние сервисы
├── Modules/
│   ├── Catalog/               # Товары, категории, коллекции, фото
│   ├── Inventory/             # SKU и остатки вариантов
│   ├── Cart/                  # Корзина
│   ├── Orders/                # Заказы и позиции заказа
│   ├── Customers/             # Покупатели и адреса
│   ├── Payments/              # Оплата и webhooks
│   ├── Shipping/              # Доставка
│   ├── Promotions/            # Промокоды и скидки
│   └── Notifications/         # Email, SMS и push
└── Program.cs                 # Сборка приложения и регистрация модулей

my-app/src/
├── app/                       # Инициализация приложения, роутинг
├── pages/                     # Страницы, собирающие готовые блоки
├── widgets/                   # Header, Footer, ProductGrid
├── features/                  # Корзина, вход, checkout, фильтры
├── entities/                  # Product, Order, Customer
├── shared/
│   ├── api/                   # HTTP-клиент и API-контракты
│   ├── config/                # Переменные окружения
│   ├── lib/                   # Переиспользуемые функции
│   ├── types/                 # Общие TypeScript-типы
│   └── ui/                    # Кнопки, поля, модальные окна
└── assets/                    # Локальные изображения и шрифты
```

Каждый backend-модуль делится на четыре слоя:

- `Domain` — сущности и бизнес-правила;
- `Application` — команды, запросы, DTO и интерфейсы;
- `Infrastructure` — реализация БД и внешних интеграций;
- `Endpoints` — HTTP endpoints конкретного модуля.

Модули не должны обращаться напрямую к таблицам и внутренним классам друг друга. Их взаимодействие проходит через публичные application-контракты.
